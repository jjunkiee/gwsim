## M1 foes

Vehtendi Valley's Foes section lists all eight Kournan foes under
"Humans (Kournan military)", each at **20 (26)**, matching §20.2 and D24.
The page's other groups (Behemoths, Margonites, Hekets, plants) and its four
bosses are recorded by `gwsim-extract roster "Vehtendi Valley"` but are not
M1 content.

## Decisions

- **The index is regenerated, not seeded.** `gwsim-extract index` replaces
  `data/skills/index.ron` wholesale, unlike `seed`, which never overwrites.
  The index is facts only and is never hand-edited, so the no-overwrite rule
  (Q10), which protects hand-written encodings, does not apply to it. Logged
  as fallout F2.4.
- **Allegiance skills keep both ids** under their disambiguated list names, so
  coverage counts them as the two skills the game has.
