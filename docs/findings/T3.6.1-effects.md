# T3.6.1 — Effect stacking, conditions, removal and knockdown

**Date:** 2026-09-23 · **Status:** Done · **Feeds:** T3.6.2–T3.6.10

Sources: `research/Effects/` (Effect, Effect stacking, Condition) and
`research/Game_mechanics/` (Knock down, Death), with the Hex spell and Enchantment spell
notes in `research/Skill_types/`.

## Stacking

| Case | Rule | gwsim |
| --- | --- | --- |
| The same skill's effect on the same target, twice | the new application **replaces** the old (most skills do not stack with themselves) | `Replace` keyed by the effect id, unless the file says otherwise |
| Conditions | one instance per condition; a new application only lengthens it if it would last longer | `KeepLonger` |
| Stances, preparations, glyphs, forms, weapon spells, bundles, party bonuses | **one at a time per character**; a new one of the family replaces the old | `EffectKind::one_at_a_time_family` (ENG-32) |
| Different skills changing the same stat | each applies; random chances multiply (50% + 50% block is 75%); movement and attack speed multiply under caps | `stats::combine` with the ENG-33 caps |
| The same effect from several casters | per skill; the files say `StackBySource` where the wiki says it stacks | — |

"Strongest wins" appears on the wiki for a few effects; none in M1 needs it, so gwsim has
no `Strongest` rule yet.

## Removal

- Hex and enchantment removal takes the **most recently applied** first — which is why
  players "cover" important hexes. gwsim sorts candidates newest first.
- Condition removal without a named condition takes the most recent condition first
  (the same convention; the wiki does not say otherwise).

## Conditions

| Condition | Effect | Who can suffer it |
| --- | --- | --- |
| Bleeding | −3 health regeneration | fleshy only |
| Poison | −4 | fleshy only |
| Disease | −4; spreads to **adjacent** creatures of the **same creature type** | fleshy only |
| Burning | −7 | anyone, spirits included |
| Deep Wound | −20% maximum health, −20% healing received | not spirits |
| Blind, Cracked Armor, Crippled, Dazed, Weakness | as their pages say | not spirits |

- Condition effects do not scale; only their durations do.
- **Spirits are immune to hexes and to every condition but Burning.**
- **Duration reductions** each apply and round separately, to the second: two 20%
  reductions on an 8 s Blind each remove 2 s (1.6 rounds up), leaving 4 s. Tested.
- Disease spreading is not modelled in M0; it needs a Disease source in M1 first and is
  logged as fallout.

## Knockdown

- The default knockdown lasts **2 s**. It stops the current action (it is not an
  interrupt, so interrupt protection does not help).
- While knocked down, only skills outside the action queue can be used: **stances,
  shouts and pet attacks**. Tested.

## Death

- Death ends the dead creature's effects, apart from a few consumables and morale, which
  M1 does not model.
- The **caster's** death ends only its maintained enchantments and a few hexes that
  depend on the caster (Life Transfer). gwsim ends maintained enchantments.
- End effects fire on some endings and not others, and which depends on the skill. The
  DSL's `on_end` runs on expiry and removal; replacement and death skip it, which matches
  every M1 skill that has one.

## Duration modifiers

Duration bonuses and reductions multiply the base duration, then the result rounds to the
nearest second, except condition reductions, which subtract separately (above).
