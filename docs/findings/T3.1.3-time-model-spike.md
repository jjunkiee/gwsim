# T3.1.3 Time-model spike, and the T3.1.4 decision

- **Tasks:** T3.1.3, T3.1.4. **Date:** 2026-09-23.
- **Question:** should continuous processes (movement, regeneration, AI
  cadence) run on a fixed 50 ms tick alongside the event queue (B), or be
  solved analytically between events (A)?

## Workload

16 units move towards targets at 288 gwinches per second (A-001), attack
every 1.5–2 s, regenerate 2 HP/s and stop at 144 gwinches, for 60 s of game
time. Each prototype ran 1,000 seeds in release on the development machine
(`crates/gwsim-engine/examples/time_model_spike.rs`, deleted after this
decision per T3.1.4).

## Measurements

| Model | 1,000 runs | Per 60 s run | Deterministic (same seed, same hash) |
| --- | --- | --- | --- |
| A — pure events | 9.4 ms | 0.009 ms | yes |
| B — events + 50 ms tick | 42.7 ms | 0.043 ms | yes |

Scaled to a 180 s fight, B's tick overhead is about 0.13 ms — 1% of the 10 ms
budget (D19). Speed does not decide between them.

## Complexity

- **Movement cancels activation.** B: a unit that moves in a tick cancels its
  activation in that tick. A: every order that starts movement must be
  intercepted and every future arrival re-planned.
- **"Enter range, then cast".** B: the approach is re-checked each tick and
  the cast starts on the first tick in range. A: an arrival event has to be
  scheduled and **invalidated whenever the target moves** — and targets move
  constantly. The spike's A cheats by only updating a unit on its own attack
  events, which is exactly the part a real engine cannot skip.
- **Body-blocking and projectile leading** need positions at arbitrary times.
  B has them at every tick; A needs closed-form trajectories for every unit,
  which body-blocking breaks.
- **AI cadence and natural regeneration** (a 5 s timer, then +1 pip per 2 s)
  are periodic. B gets them for free; A needs a recurring event per unit.

## Decision (T3.1.4)

**B, the hybrid model**, as DESIGN §10.2 proposed. Time is integer
milliseconds; discrete things (activation end, aftercast end, effect expiry,
projectile impact, attack hits) are events ordered by (time, priority class,
insertion sequence); movement, regeneration and AI decisions advance on a
50 ms tick, with health and energy accumulated in fixed point so whole-second
totals are exact. A was faster in the spike, but only because the spike
skipped the re-planning a real engine needs, and B is already two orders of
magnitude inside the budget.
